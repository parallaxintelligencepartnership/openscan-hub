# Changelog

## 0.4.0

- Scan profiles: pick one on the phone page or the dashboard, then load the feeder.
- OCR to searchable PDF, deskew, auto-rotate, crop, compression and PDF/A.
- Smart file names from the page: date, title, vendor.
- Separator pages split one feeder stack into several files.
- New destinations: SMB share, WebDAV or Nextcloud, and email.
- New inputs: an SMB share on a NAS and an email inbox.

## 0.3.2

- Dependency updates. No behavior changes.

## 0.3.1

- Shows a red warning when settings cannot be saved, and the log says how to fix it.

## 0.3.0

- First version of the Home Assistant add-on.
- Opens in the Home Assistant sidebar (ingress).
- Scans folder and FTP receiver are set on the add-on Configuration tab.
